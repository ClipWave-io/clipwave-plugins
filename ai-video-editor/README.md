# AI Video Editor & Timeline by ManyMotions

Give Claude a real video editor: generate shots, cut them on a multi-track timeline, burn in captions and export an MP4 from your ManyMotions account.

## What it does

Claude creates a project with a shared media library and one or more videos, fills the library with generated shots and images or with public media URLs, places clips on the video, voice, sfx and music tracks, trims, reorders and sets transitions, burns in captions (static, word-pop or karaoke) and exports the finished MP4. Placing, removing, reordering, transitions, captions, reading the timeline and exporting are deterministic and free; generating media and the editor agent spend credits.

**AI generation:** the media are generated by AI models run by ManyMotions and its model providers. Nothing is generated until you ask for it, and the credits required are shown first.

Generation is billed per model and shown in the result; exports are free.

## Setup

The plugin connects Claude to the ManyMotions MCP server at `https://manymotions.com/api/mcp` (Streamable HTTP).

- Connecting asks you to sign in to ManyMotions (OAuth with PKCE and dynamic client registration; you can create an account on the same page). Every tool runs on your account.
- Generation and the editor agent need verified paid access and available credits; reading, timeline edits and exports do not spend credits.
- Claude Code: run `/mcp`, pick **ai-video-editor** and sign in.

## Tools

| Tool | What it does |
|---|---|
| `list_models` | Model catalogue with exact ids. Free. |
| `media_forge_generate` | Generate a video or image. Uses credits. |
| `job_status` | Poll a generation job. Free. |
| `video_editor_create_project` | Create a project with a shared library. |
| `video_editor_get_timeline` | Read every clip in order with durations. Free. |
| `video_editor_add_reference` | Import a public image, video or audio URL. |
| `video_editor_add_clip` | Place a library asset on a track. |
| `video_editor_reorder_clip / remove_clip / set_transition` | Deterministic timeline edits. Free. |
| `video_editor_upload_captions` | Burn in SRT or VTT captions. |
| `video_editor_instruct` | One instruction to the editor agent; may generate media and spend credits. |
| `video_editor_export` | Render the timeline to an MP4. Free. |

## Example prompts

- "Generate three 5-second shots of a ceramic mug on a windowsill, cut them together with short fades, add TikTok-style captions and export vertical"
- "Open my latest ManyMotions project, show me the timeline and move the last clip to the start"
- "Import these two video URLs, put them back to back with a crossfade and export an MP4"

## Data and privacy

Your prompts and settings are sent to ManyMotions and stored in your ManyMotions account, and they are sent to the model providers that render the media. The plugin has no hooks or local scripts and sends nothing else.
